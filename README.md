# Python Essentials - Parte 2

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Python Essentials - Parte 2**. Aquí podrás continuar desarrollando tus habilidades de programación en Python mediante prácticas guiadas enfocadas en estructuras de control, colecciones de datos, funciones y manejo de excepciones.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### [Capítulo 1. Ciclos y control de flujo](Capitulo_1/README.md)

* **Práctica 1.1. Rangos**

  * **Descripción**: Utilizar la función `range()` y ciclos `for` para generar y recorrer secuencias numéricas con diferentes incrementos.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 1.2. Menú**

  * **Descripción**: Implementar un menú interactivo utilizando ciclos `while`, estructuras condicionales y validación de datos ingresados por el usuario.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 1.3. Control de flujo**

  * **Descripción**: Analizar el comportamiento de ciclos `while`, la cláusula `else` y la instrucción `break` para controlar el flujo de ejecución de un programa.
  * ⏱️ **Duración estimada**: 8 min.

---

### [Capítulo 2. Colecciones de datos](Capitulo_2/README.md)

* **Práctica 2.1. Listas y comprensión de listas**

  * **Descripción**: Crear y manipular listas, realizar operaciones de acceso, búsqueda y copia, y generar nuevas listas mediante List Comprehension.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 2.2. Slicing de listas**

  * **Descripción**: Utilizar slicing para dividir listas en sublistas y calcular su punto medio mediante `math.ceil()`.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 2.3. Diccionarios**

  * **Descripción**: Crear y utilizar diccionarios para almacenar información mediante pares clave-valor, modificar sus valores y realizar cálculos con los datos almacenados.
  * ⏱️ **Duración estimada**: 8 min.

---

### [Capítulo 3. Funciones](Capitulo_3/README.md)

* **Práctica 3.1. Funciones y parámetros**

  * **Descripción**: Crear funciones reutilizables, comprender la diferencia entre parámetros y argumentos e invocar funciones utilizando diferentes tipos de datos.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.2. Funciones con parámetros y valores de retorno**

  * **Descripción**: Crear funciones que reciban parámetros y devuelvan resultados mediante `return`, aplicándolas al cálculo del Índice de Masa Corporal (IMC).
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.3. Diseño modular con funciones**

  * **Descripción**: Diseñar una aplicación modular mediante funciones especializadas, reutilizando código y validando los datos ingresados por el usuario.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.4. Parámetros con valores predeterminados**

  * **Descripción**: Crear funciones con parámetros predeterminados e invocarlas utilizando diferentes cantidades de argumentos.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.5. Funciones y comprensión de listas**

  * **Descripción**: Crear funciones que procesen colecciones de datos mediante comprensión de listas y manipulación de cadenas de texto.
  * ⏱️ **Duración estimada**: 8 min.

---

### [Capítulo 4. Manejo de excepciones](Capitulo_4/README.md)

* **Práctica 4.1. Manejo de excepciones**

  * **Descripción**: Identificar diferentes tipos de excepciones y utilizar estructuras `try` y `except` para controlar errores durante la ejecución de programas.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 4.2. Sumar indefinidamente**

  * **Descripción**: Utilizar excepciones para validar entradas de datos, implementar un proceso de suma repetitiva y controlar errores mediante `try-except`.
  * ⏱️ **Duración estimada**: 8 min.
